YouTube Channel Banner — Pixel-Exact Master Prompt

A copy-and-paste master prompt for creating a YouTube banner that keeps all essential content inside the all-devices crop area.

Copy-and-Paste Prompt

Please create youtube banner....
        
        YOUTUBE CHANNEL BANNER — PIXEL-EXACT MASTER PROMPT

Create a finished YouTube channel banner that will display correctly on ALL DEVICES.

IMPORTANT:
This is a precision layout task, not merely an image-generation task.

DO NOT rely on the image generator to position or size the final text, logos, people, signs, or other essential elements.

==================================================
FINAL FILE REQUIREMENTS
==================================================

1. Create the FINAL image programmatically as an EXACT:

2560 × 1440 pixel PNG.

2. The final PNG itself must be exactly 2560 × 1440 pixels.

Do NOT create a short panoramic banner and simply place it inside a 2560 × 1440 canvas.

The background artwork must fill the entire 2560 × 1440 canvas edge-to-edge.

3. YouTube crops channel banners differently on TV, desktop, mobile, and other devices.

Therefore, ALL ESSENTIAL CONTENT must fit completely inside YouTube's centered "All devices" safe area.

Essential content includes:

- every word of the title
- subtitle
- logos
- signs or stamps
- people, if they must appear on all devices
- important objects
- any other element I need every viewer to see

Decorative scenery does NOT need to fit inside the safe area.

==================================================
USE MY YOUTUBE SCREENSHOT AS THE CROP TEMPLATE
==================================================

4. If I provide a screenshot of YouTube's "Customize banner art" screen showing the blue crop boxes, treat MY SCREENSHOT as the authoritative crop template.

DO NOT guess the safe area.

DO NOT assume that an approximate safe-area specification will match what YouTube is showing me.

Instead:

- inspect my screenshot;
- identify the actual blue rectangle labeled "All devices";
- measure its left, right, top, and bottom boundaries;
- determine its position relative to the full YouTube banner rectangle shown in the screenshot;
- translate those proportions to the exact 2560 × 1440 master canvas;
- place ALL essential content completely inside those translated boundaries.

Leave additional padding inside the safe area.

Do NOT place important lettering directly against the safe-area boundary.

5. If I have NOT supplied a YouTube crop-preview screenshot, use YouTube's CURRENT official recommended banner and all-device safe-area specifications.

Because YouTube specifications can change, verify the current specifications from YouTube's official documentation before constructing the final file.

==================================================
BACKGROUND VS. ESSENTIAL CONTENT
==================================================

6. Separate the design mentally into two layers:

LAYER A — DECORATIVE BACKGROUND

This can fill the entire 2560 × 1440 image.

Examples:

- theater
- curtains
- ceiling
- lights
- balconies
- auditorium
- seats
- stage floor
- scenery
- atmospheric lighting

It is perfectly acceptable for YouTube to crop portions of these elements on different devices.

LAYER B — ESSENTIAL CONTENT

This must remain completely inside the "All devices" safe area.

Examples:

- title
- subtitle
- logo
- SOLD OUT sign
- important people
- essential objects
- essential wording

It is NOT acceptable for YouTube to crop any portion of these elements.

==================================================
CRITICAL — USE A CLEAN BACKGROUND
==================================================

7. If existing artwork already contains:

- title text
- subtitle text
- logos
- SOLD OUT signs
- people
- lettering
- stamps
- or other elements that will be repositioned

DO NOT simply use that pre-lettered artwork as the background and place new material over it.

That will create duplicate giant text, duplicate signs, or unwanted artwork underneath the final composition.

Instead, create or use a CLEAN background containing ONLY the desired scenery.

For example, if this is a theater banner, the clean background should contain:

- theater
- curtains
- lights
- seats
- stage
- atmosphere

but NO title, NO subtitle, NO SOLD OUT sign, and NO other lettering.

==================================================
IMAGE GENERATION VS. FINAL COMPOSITION
==================================================

8. Image generation MAY be used to create visual assets such as:

- clean theater scenery
- curtains
- stage
- lighting
- atmosphere
- people
- objects
- decorative artwork

However:

DO NOT use image generation to construct the final pixel-exact YouTube banner.

Once the visual assets exist, STOP using image generation for the final layout.

Use exact programmatic image editing/compositing for the final 2560 × 1440 PNG.

9. Final text should be added programmatically whenever accurate wording, size, or placement matters.

Do NOT ask the image generator to render final important text if spelling and positioning need to be exact.

Programmatically control:

- font size
- text width
- text height
- horizontal position
- vertical position
- alignment
- spacing
- margins
- sign dimensions

==================================================
SAFE-AREA FITTING
==================================================

10. Do not merely center the essential content and assume it fits.

Actually calculate its bounding boxes.

Before producing the final file, verify programmatically that:

TITLE bounding box
is completely inside the All Devices safe area.

SUBTITLE bounding box
is completely inside the All Devices safe area.

LOGO bounding box
is completely inside the All Devices safe area.

SIGN/STAMP bounding box
is completely inside the All Devices safe area.

PEOPLE/OBJECT bounding boxes
are completely inside the All Devices safe area IF they are designated as essential.

11. If something does not fit:

DO NOT enlarge the canvas.

DO NOT change the YouTube dimensions.

Instead:

- make the element smaller;
- rearrange the composition;
- shorten the vertical stack;
- move elements horizontally;
- move elements vertically;
- reduce spacing;
- redesign the layout.

Continue until ALL essential content fits comfortably inside the All Devices safe area.

==================================================
SAFE-AREA PROOF
==================================================

12. Create TWO finished PNG files.

FILE A — FINAL YOUTUBE BANNER

Exact size:

2560 × 1440 pixels

This is the clean finished banner I will actually upload to YouTube.

It must contain NO:

- crop guides
- blue rectangles
- green rectangles
- measurement labels
- dimensions
- safe-area markings
- instructional text

FILE B — SAFE-AREA PROOF

Create an identical copy of the final banner.

On this proof copy ONLY, draw a clearly visible rectangle showing the exact All Devices safe area.

The rectangle should demonstrate that every essential element fits completely inside it.

The proof is for inspection only.

==================================================

==================================================

13. BEFORE giving me the files, inspect and verify ALL of the following:

[ ] Final PNG is exactly 2560 × 1440 pixels.

[ ] Background fills the complete 2560 × 1440 canvas.

[ ] There are no accidental blank bars caused by inserting a short panoramic image into a taller canvas.

[ ] There is only ONE copy of the title.

[ ] There is only ONE copy of the subtitle.

[ ] There is only ONE copy of each sign/logo/stamp.

[ ] Every essential element is completely inside the All Devices safe area.

[ ] Essential elements have comfortable additional margin from the safe-area boundaries.

[ ] Nothing important is likely to be clipped on mobile.

[ ] Text spelling is exact.

[ ] Text is readable.

[ ] Elements do not overlap accidentally.

[ ] Final banner contains no crop guides.

[ ] Proof version clearly shows the safe-area boundary.

[ ] The proof demonstrates that everything essential fits.

If ANY item fails, FIX IT before giving me the files.

==================================================
IMPORTANT FAILURE PREVENTION
==================================================

14. Do NOT repeatedly generate wider and wider pictures in an attempt to solve YouTube cropping.

The issue is not simply the aspect ratio of the artwork.

The final deliverable must be an exact 2560 × 1440 master image with essential content deliberately composed inside YouTube's much smaller centered All Devices region.

15. Do NOT confuse:

"the artwork is 2560 × 1440"

with:

"the important artwork fits the All Devices safe area."

Those are TWO DIFFERENT requirements.

Both must be satisfied.

16. If my actual YouTube preview screenshot appears to conflict with an assumed or published safe-area specification:

FOLLOW THE CROP BOX SHOWN IN MY SCREENSHOT.

My actual YouTube preview is the final test.
