Exact Facebook Bridge

  1. Confirm the approved image and caption. Do not publish an unapproved preview.
  2. Publish the full-resolution image using the existing public Drive → GitHub Actions bridge. Verify the image exists before queuing.
  3. Use private GitHub repository gomuller/jesus-greg-mission-control, branch main, file facebook-publishing/request.json.
  4. Fetch the current request and SHA, then update with a unique id, status: "pending", verified public image_url (prefer https://raw.githubusercontent.com/gomuller/zioncoalition/main/FILENAME), and approved caption (empty string for image-only).
  5. The Windows facebook-bridge.js Playwright worker polls approximately every 30 seconds. Inspect queue status after submission.
  6. Verify the Facebook timeline/permalink before claiming success. If needs-review or a Playwright timeout occurs, check for an existing post before retrying to avoid duplicates.
  7. Report whether Facebook publication is confirmed, pending, needs review, or blocked. Complete gallery publication separately when requested.
