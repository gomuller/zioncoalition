MASTER PROMPT — JESUS PILLOW VERBATIM TEXT

00-12 · Preserve the pillow. Preserve the words. Change only what Greg requests.

Purpose

Use this master prompt to make or update the Jesus Pillow photograph with dense, no-spaces text, alternating near-black and charcoal-gray words. It works together with 00-08 — Image Preservation & Surgical Editing.

THE USER'S CURRENT AUTHORITATIVE TEXT IS THE SOURCE OF TRUTH. NEVER TRANSCRIBE A PREVIOUSLY GENERATED IMAGE AS THE SOURCE.

How to use

  1. Attach the most recently approved pillow image, or specify a new blank pillow background.
  2. Paste the full authoritative text, or provide the exact new replacement text and any precise edits.
  3. Say: “Apply 00-12 Jesus Pillow Text. Use this exact text: …”
  4. For revisions, specify where the new material goes. If only a suffix is supplied, preserve the previously approved authoritative text and append the suffix exactly.
  5. Review the final image and approve it before treating it as the next visual master.
  6. When adding handwriting, provide the handwritten image or mockup; preserve its exact strokes, words, and placement as a separate overlay without changing the printed paragraph.

MASTER PROMPT — Copy and reuse

MASTER PROMPT — 00-12 JESUS PILLOW VERBATIM TEXT TASK: Create or edit a photorealistic white Jesus Pillow bearing a dense block of text with NO SPACES BETWEEN WORDS, alternating near-black and lighter charcoal-gray word colors. APPROVED PILLOW IMAGE: [ATTACH CURRENT APPROVED IMAGE] AUTHORITATIVE TEXT: [PASTE COMPLETE EXACT TEXT OR IDENTIFY THE PREVIOUSLY APPROVED SOURCE TEXT] AUTHORIZED CHANGE: [EXACT REPLACEMENT, INSERTION OR APPEND INSTRUCTION] 1. VERBATIM TEXT LOCK — HIGHEST PRIORITY The authoritative text supplied by Greg is controlling. Copy its characters exactly. Do not paraphrase, fix grammar, normalize repeated words, invent words, omit text, add words, or silently correct unusual spelling. Preserve capitalization, apostrophes, curly quotes, punctuation, hyphens, em dashes, hashtags, equal signs, and exact ordering. Intentional repetitions such as “andand” must remain repetitions. If the user supplies already concatenated text, preserve it character-for-character. If the user supplies normal prose and asks for no spaces, remove only interword whitespace; retain all other characters. Do not delete punctuation or replace it with a space. 2. NO-SPACE TYPOGRAPHY No spaces between adjacent words. Visual line wrapping is allowed but is not a new character in the authoritative string. Alternate word color (A: near-black #111111; B: charcoal #666666) according to the ORIGINAL word boundaries before spaces are removed. Colors change, not the letters or their positions. Punctuation stays attached to its word. Never introduce a visible gap to achieve alternating colors. Use a clean, readable, compact sans-serif font; preserve the approved typography if editing an existing image. 3. PILLOW VISUAL LOCK Preserve the latest approved large white rectangular pillow, softly wrinkled white fabric, subtle seams, cream bedding, natural soft light, straight-on camera angle, shadows, and crop. Do not alter bedding, fabric, perspective, background, lighting, or other text unless explicitly authorized. Treat 00-08 Image Preservation as simultaneously active. 4. EXACT-TEXT RENDERING METHOD For lengthy passages, DO NOT depend on generative image lettering for accuracy. Prefer a deterministic text overlay (SVG, HTML/CSS rendered to image, Pillow, or equivalent) applied over the approved pillow photograph. Maintain the existing approved photo as the base. Re-typeset only the necessary text region. For a small append, preserve the existing photograph and approved unaffected text; extend/reflow the text region only if required to fit the exact words. If a generator must be used, disclose that its lettering cannot be guaranteed verbatim, and verify rather than claiming perfection. 5. EDIT RULE When Greg says “keep everything the same and add after #HearHim,” the new words must be appended AFTER the existing #HearHim, not substituted, rewritten, or approximated. Do not duplicate #HearHim unless the literal new text includes it. If the appended literal string begins with #HearHim, keep that repetition because Greg specified it. Ask only if the instruction is genuinely ambiguous. 6. SPECIAL WARNING FROM THE OCTOBER 2026 FAILURE The prior pillow-image update corrupted the final suffix. The requested literal suffix was: #HearHimNot#HearGregandandkeepinmindthisismycurrentbestguessusingmysacredimagination The generated image did not reproduce it correctly. Never use the mistaken image lettering as canonical text. In particular, protect the exact sequence “andand”, “thisismycurrentbestguess”, and “usingmysacredimagination”. This example is a quality-control reference, NOT a suffix to add to every future image. 7. VERIFICATION BEFORE DELIVERY Store the exact expected output text as a separate master string. Check that all content from beginning to end matches it, with particular attention to the final 15% and the final line. When possible compare the exact string fed to the renderer against the canonical string programmatically. Verify punctuation, hashtags, repetition, capitalization, and word count. Inspect text wrapping, legibility, clipping, and edges. A string-level check proves the renderer input, not necessarily the visual output: also visually inspect the result. Never say “verbatim” or “perfect” if exact visual accuracy has not been verified. If a generated image contains errors, correct it rather than quietly accepting them. 8. APPROVAL AND VERSION CONTROL The most recently APPROVED visual result is the image master. The most recently supplied AUTHORITATIVE TEXT is the text master. These are separate: approval of a picture does not turn its possibly erroneous lettering into authoritative wording. Future edits change only what Greg specifies. 9. HANDWRITTEN OVERLAY LOCK — USER-ADDED LETTERING When Greg supplies handwritten words, lettering cutouts, or a reference image showing their placement, treat them as separate, authorized overlay elements—not as part of the dense no-space body paragraph unless explicitly instructed. Preserve the handwriting's exact wording, spelling, capitalization, punctuation, distinctive cursive strokes, slant, line weight, proportions, and overall visual character. Place each handwritten element where Greg indicates, matching approximate size, rotation, alignment, and visual relationship to the pillow and printed paragraph. The handwritten lettering may naturally include spaces; the no-spaces rule applies ONLY to the dense body paragraph unless Greg explicitly extends it to the handwriting. Use the supplied handwriting as the visual master whenever available: isolate and composite the actual lettering, with transparency if necessary, rather than recreating it in a generic font. Clean up the background or improve contrast only if requested. Keep all existing printed text, bedding, pillow fabric, lighting, and other lettering unchanged except for expressly authorized placement adjustments. Never let an overlay obscure, delete, or silently rewrite the body text. 10. OCTOBER 2026 HANDWRITING EXAMPLE Greg supplied a pillow mockup with two black, sweeping handwritten phrases: at the top, “Axl Rose & November Rain is a Liahona!”; at the bottom, “The Liahona is Jesus TV”. He instructed: “leave everything the same...but add the handwritten stuff as shown here”. The desired operation was to add BOTH phrases in their shown locations and distinctive handwritten style while retaining the approved white pillow and entire dense, alternating-black-and-charcoal paragraph unchanged. This is an EXAMPLE of how to handle future handwritten additions, NOT an instruction to add those two phrases to every new pillow. The reference mockup controls the placement and handwriting; the authoritative source text controls the printed paragraph. 11. HANDWRITING VERIFICATION Check each handwritten phrase character by character against Greg's wording, including names such as “Axl Rose”, ampersands, punctuation, and capitalization. Confirm the top/bottom placement, stroke appearance, and that the paragraph remains intact. For future handwritten edits, retain previously approved handwritten overlays unless Greg explicitly asks to alter or remove them. FINAL RULE: SOURCE TEXT FIRST. EXACT LETTERS SECOND. PILLOW STYLE THIRD. NEVER SACRIFICE TEXT ACCURACY TO MAKE THE PICTURE LOOK BETTER.

Recommended production workflow

Keep a plain-text canonical master alongside the image. For each revision, apply the requested edit to that text, create the no-space alternating-color overlay deterministically, place it over the original approved pillow photo, and inspect the entire image before delivering. The photo remains stable even when the paragraph grows or shrinks.

Technical limitation: A prompt alone cannot guarantee flawless lettering in a generative image. Exact text is best ensured through deterministic typography and source-string checks, followed by visual inspection.
