MASTER PROMPT — MOVIE AUDIO COMPATIBILITY

00-09 · Preserve the picture. Make the voice reliably audible.

Why this exists

During 500 Redeemed Memories (October 2026), an MP4 appeared to contain narration but the user could not hear it in their player. A subsequent H.264 MP4 with boosted, stereo AAC narration played successfully. This records a tested output profile, not a proven diagnosis of the earlier failure.

Locked successful delivery profile: MP4 container; H.264 video; AAC-LC stereo audio; 192 kb/s audio; 48 kHz sample rate; +faststart; voice gain adjusted conservatively without clipping. Preserve the source video and the natural recorded voice.

Pre-prompt for future ChatGPT sessions

Reusable master prompt

MASTER PROMPT — AUDIO PLAYBACK / COMPATIBILITY

INPUTS: [VIDEO FILE] and [VOICE RECORDING]
OUTPUT: [NEW VERSIONED MP4]

1. INSPECT FIRST. Use ffprobe to report duration, video codec, audio codec, channel count, sample rate, bitrate and stream start times. Use ffmpeg volumedetect or loudnorm analysis to check actual audio signal. A listed audio stream alone does NOT prove audible playback.

2. PRESERVE APPROVED WORK. Keep scene order, picture content, frame dimensions, and original spoken words. Do not cut or re-time narration unless requested. Never overwrite the master.

3. EXPORT FOR COMPATIBILITY. Use an MP4 container, H.264/yuv420p video, AAC-LC audio, 2 channels (stereo), 48000 Hz, 192 kb/s, and movflags +faststart. A mono source may be safely converted to stereo without changing its voice identity.

4. SET VOICE LEVEL SAFELY. Analyze peak and loudness first. Raise volume only as needed. Avoid clipping and distortion; apply peak limiting if necessary. A previous working export used a boosted voice, but do not blindly apply a fixed multiplier to every recording.

5. VALIDATE. Probe the rendered file again. Decode its audio to PCM and measure non-silent portions near the beginning, middle and end. Check the voice starts where intended and is not truncated. Ideally audition the exported result; if audio audition is unavailable, say so.

6. DELIVER A NEW VERSION. Provide a verified file link and concise codec details. Ask whether I can actually hear it in my player. Lock the compatible export settings after I confirm.

7. IF STILL SILENT. First test the standalone MP3 and a short audio-only AAC/M4A extract. Compare local playback with browser preview. Do not assume the codec is the only possible cause.

FFmpeg reference recipe

Use this as a starting point after measuring the source levels. This example keeps the video timing and adds an audio track; replace filenames. It uses video copy only when the source video is already H.264/yuv420p-compatible; otherwise re-encode the video as shown.

ffmpeg -i input_video.mp4 -i narration.mp3 \
  -map 0:v:0 -map 1:a:0 \
  -c:v libx264 -pix_fmt yuv420p -crf 20 -preset medium \
  -c:a aac -b:a 192k -ac 2 -ar 48000 \
  -af "alimiter=limit=0.95" \
  -movflags +faststart output_stereo.mp4

Important: this command does not automatically pad video to the audio length, synchronize scene timing, or normalize loudness. Handle those separately when needed. For already compatible video, -c:v copy avoids unnecessary picture re-encoding.

Acceptance test

Only declare success after the user confirms: “I can hear it.” Preserve that approved profile in all later revisions unless a specific change is requested. For timing edits, use 00-10 Narration / Scene Sync.
