MASTER PROMPT — IMAGE PRESERVATION & SURGICAL EDITING

00-08 · Lock the approved image. Change only what is requested.

Purpose

This is a universal master prompt for editing an existing approved image without unintended changes. It applies to photographs, memes, book covers, signs, portraits, posters, Jesus TV scenes, architectural compositions, and all other visual artwork.

PRESERVE FIRST. MODIFY SECOND. NEVER RECREATE WHAT IS ALREADY APPROVED.

Unlike a style prompt, this prompt establishes change control: the current approved image is authoritative, and only specifically authorized areas or elements may be modified.

How to Use

  1. Provide the most recently approved full image as the MASTER IMAGE. A previous description or an older image is not a substitute.
  2. Provide any original portraits, posters, book covers, or other reference assets whose details must remain faithful.
  3. Specify the exact change and its location. Identify anything that must stay in front of or behind the edited element.
  4. Tell ChatGPT: “Apply 00-08 Image Preservation. Make only this change: …”
  5. Inspect the result against the master before approving it as the new master.
Important: A URL, filename, or HTML image tag does not prove that ChatGPT has actually inspected an image. If the master or essential reference cannot be accessed, request the image attachment rather than inventing its appearance.

Master Prompt — Copy and Reuse

MASTER PROMPT — IMAGE PRESERVATION & SURGICAL EDITING TASK TYPE: EDIT THE APPROVED IMAGE; DO NOT RECREATE IT. MASTER IMAGE: [ATTACH THE MOST RECENTLY APPROVED FULL IMAGE] REFERENCE ASSETS: [ATTACH ORIGINAL PHOTOS / POSTERS / COVERS, IF NEEDED] AUTHORIZED CHANGE(S): [STATE EXACTLY WHAT TO CHANGE] EDIT LOCATION(S): [STATE WHERE EACH CHANGE GOES, INCLUDING FRONT/BEHIND RELATIONSHIPS] EVERYTHING ELSE IS LOCKED. ======================================================== 1. MASTER IMAGE IS AUTHORITATIVE ======================================================== The supplied approved image is the controlling source. Do not redesign, reinterpret, enhance, regenerate, rearrange, restyle, or "fix" any unmentioned element. Preserve the original: • composition, framing, crop, dimensions and aspect ratio • camera viewpoint, perspective, lighting and shadows • colors, textures, architecture and background • people, faces, expressions, clothing and poses • typography, spelling, punctuation and exact text • signs, posters, objects, decorative details and their positions • borders, frames, logos, watermarks and plaques • relative sizes, spacing, occlusion and depth order Do not add new objects or remove existing objects unless instructed. ======================================================== 2. DEFINE THE EDIT MASK — EVERYTHING ELSE IS LOCKED ======================================================== Change only the specifically authorized region or element. Treat all pixels outside that region as protected whenever technically possible. For each change, identify: • the object or area being edited • what must be replaced, inserted, removed or adjusted • its exact location and intended size • which existing elements overlap it • whether it sits in front of or behind those elements If the request is ambiguous enough to risk changing an important approved element, ask one concise clarifying question before editing. ======================================================== 3. REFERENCE ASSETS ARE SOURCE MATERIAL, NOT INSPIRATION ======================================================== When an original photo, face, book cover, poster, or other graphic is supplied, preserve its identity and visual details faithfully. Prefer inserting or compositing the actual supplied asset. Do not redraw faces or approximate the original from a text description. Do not invent new text or redesign supplied typography. Only apply necessary resizing, perspective correction, cropping when authorized, masking, and subtle lighting integration. If a faithful composite is not possible with the available tools, state that limitation rather than claiming an exact match. ======================================================== 4. PREFER LOCALIZED COMPOSITING OVER WHOLE-IMAGE GENERATION ======================================================== Use non-generative image compositing for exact preservation when available. Otherwise use targeted, masked editing rather than regenerating the full scene. If only a generative editor is available, recognize that it may alter unmasked details, text, faces, or framing despite these instructions. Never promise pixel-perfect fidelity from a method that cannot guarantee it. Do not call an image "unchanged" without checking it. ======================================================== 5. PRESERVE EXACT TEXT ======================================================== Treat existing and supplied text as visual source material. Do not paraphrase, respell, abbreviate, change capitalization, add punctuation, omit lines, or replace unusual wording. When text must remain exact, prefer reusing original graphic pixels or adding precisely typeset text instead of relying on image generation. ======================================================== 6. PROTECT LAYERS AND OCCLUSION ======================================================== Maintain correct front/behind relationships. If a poster belongs behind a railing, the railing must remain in front. If an object is on a stand, preserve the stand and its original position. Do not cover existing signs, windows, faces, or other protected objects unless the authorized change explicitly requires it. ======================================================== 7. COMPARE BEFORE DELIVERING ======================================================== Compare the result against the master image, checking: [ ] Overall frame, crop, proportions and perspective unchanged [ ] All unedited objects remain in their original positions [ ] Faces and likenesses remain faithful to source assets [ ] Original wording and typography remain intact [ ] Only authorized regions have changed [ ] Layer order, lighting and perspective are appropriate [ ] No unrequested additions, removals or visual drift If unintended changes are detected, correct them when possible. If they cannot be corrected, disclose the specific limitation. Do not silently present the result as an exact preservation. ======================================================== 8. APPROVAL AND VERSION CONTROL ======================================================== The newest explicitly approved result becomes the master for the NEXT edit. A newly generated result is not automatically approved. Never substitute an earlier draft for the latest approved master. When a request says "nothing else changes," interpret that literally: ONLY THE SPECIFIED CHANGE IS AUTHORIZED. FINAL RULE: PRESERVE FIRST. MODIFY SECOND. NEVER RECREATE WHAT IS ALREADY APPROVED.

Practical Editing Workflow

  1. Identify the master: Confirm which exact image is approved.
  2. Identify the references: Use the original image assets, especially for recognizable people and detailed typography.
  3. Define the change zone: Identify the smallest practical edit area.
  4. Protect the rest: Prefer a layered composite or masked edit that leaves the original pixels intact.
  5. Check the result: Compare the revised image to the master, including details outside the edited area.
  6. Promote only after approval: The approved result becomes the next master.

Special Case — Jesus TV

When the artwork is inside the standard What I See On Jesus TV frame, apply this preservation prompt together with the existing 00-07 Master Prompt — Jesus TV Frame.

00-07 defines the permanent Jesus TV frame. 00-08 controls what may change in an already approved image.

For example, when editing Victory Hall, preserve the television casing, gold trim, plaque, building, signs, sidewalk writing, and all other approved details unless a specific change is requested.

Technical Honesty — What This Prompt Can and Cannot Guarantee

A strong prompt improves editing discipline, but it is not a pixel-lock mechanism. Generative image tools can still drift in faces, signs, architecture, and text. For exact preservation, the reliable approach is direct image compositing: retain the original image and change only the selected pixels or layers.

If the task demands exact preservation and suitable compositing tools are available, use them. Otherwise, explain the risk and ask whether a less exact generative edit is acceptable.
